
# Day 10 - Python OS Module

## Overview

This project demonstrates the basic usage of Python's built-in `os` module for performing common operating system tasks. It covers directory creation, renaming folders, listing directory contents, and working with the current working directory.

## Topics Covered

* Creating multiple directories using `os.mkdir()`
* Renaming directories with `os.rename()`
* Listing files and folders using `os.listdir()`
* Getting the current working directory using `os.getcwd()`
* Changing the current working directory using `os.chdir()`

## Learning Objectives

* Understand how to interact with the operating system using Python.
* Automate directory and file management tasks.
* Learn basic navigation and manipulation of the file system.

## Requirements

* Python 3.x
* No external libraries are required.

## How to Run

Execute the Python script from the terminal:

```bash
python OS_Modules.py
```

## Note

Some code examples are commented out to demonstrate different `os` module functions. Uncomment the desired section before running the script.
