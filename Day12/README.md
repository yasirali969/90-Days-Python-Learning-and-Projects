# Day 12 – Python `time` Module

## 📖 Summary

Today, I learned how to use Python's built-in `time` module to work with time-related operations. I explored how to retrieve the current Unix timestamp, display the current time in a human-readable format, pause program execution, access local time, format date and time, and measure code execution time using a high-precision timer.

### 📚 Topics Covered
- `time.time()` – Get the current Unix timestamp.
- `time.ctime()` – Display the current time in a readable format.
- `time.sleep()` – Pause program execution for a specified duration.
- `time.localtime()` – Retrieve the current local time.
- `time.strftime()` – Format date and time using custom patterns.
- `time.perf_counter()` – Measure program execution time with high precision.

### 🎯 Learning Outcome
- Learned to work with timestamps and local time.
- Understood how to delay program execution.
- Learned to format dates and times.
- Measured program performance using a high-precision timer.
