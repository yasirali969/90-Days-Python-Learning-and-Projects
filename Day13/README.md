# Day 13 - SQLite3 with Python

On Day 13, I explored the basics of **SQLite3** in Python. I learned how to create and manage a local database, execute SQL queries, and perform basic database operations using Python's built-in `sqlite3` module.

## Topics Covered

- Importing the `sqlite3` module
- Connecting to an SQLite database
- Creating a database and tables
- Using a cursor to execute SQL commands
- Inserting records into a table
- Saving changes with `commit()`
- Retrieving data using `SELECT`
- Fetching query results with `fetchall()`
- Closing the database connection

## Technologies Used

- Python 3
- SQLite3 (Built-in Python Module)
