# File Handling in Python

## Overview

This project demonstrates the basic concepts of file handling in Python. It includes examples of reading from, writing to, and appending data to text files using Python's built-in file operations.

## Files

* **File Handling.py** – Demonstrates fundamental file handling operations.
* **Filehandling2.py** – Contains additional file handling examples.
* **Practice.txt** – Sample text file used for practice.
* **Yasir.txt** – Sample text file for input/output operations.

## Learning Objectives

* Open and close files
* Read data from text files
* Write data to files
* Append data without overwriting existing content
* Understand Python file modes (`r`, `w`, `a`)

## Requirements

* Python 3.x

## Running the Project

Run the Python scripts using:

```bash
python "File Handling.py"
```

or

```bash
python "Filehandling2.py"
```
